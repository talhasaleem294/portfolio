### How to Update the Portfolio
1. Edit the relevant file(s) locally (`index.html`, `portfolio.md`, `Talha.png`, or `Senior Software Engineer.pdf`)
2. Run the following commands:
```bash
git add index.html portfolio.md Talha.png "Senior Software Engineer.pdf"
git commit -m "Your update message"
git push
```
3. Netlify auto-detects the push and redeploys — live in ~30 seconds. No manual steps needed.

> **Note:** Never store your GitHub Personal Access Token in the remote URL or commit it. If you need to re-authenticate, generate a new classic PAT (with `repo` scope) from GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic), and use it temporarily in the push command.
